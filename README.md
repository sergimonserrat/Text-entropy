# Text-entropy
Computing the entropy of Pride and Prejudice. Part of the coursework for an Information Theory course.

## Repository structure
- `1342-0.txt`: the text of Pride and Prejudice by Jane Austen.
- `Shannon_entropy.py`: main code
- `README.md`: this file
- `Requirements.txt`: necessary python libraries and their versions

## Code description

- The text is stripped of special characters and cast into lowercase.
- Words are stored in a dictionary and counted.
- Word entropy is computed.
- The same process is applied to individual characters and the entropy per character is computed.
